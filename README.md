## 🌟 အင်္ဂလိပ်လို ဖော်ပြချက် / Description

A cutting-edge, interactive portfolio website for **Moe Kyaw Aung**, a Senior Android Developer specializing in **Kotlin**, **Jetpack Compose**, **MVVM**, and **Clean Architecture**. 

This portfolio features a **neon-cyber theme**, **3D animations**, **AI chatbot assistant**, and **Burmese language support**.

## ✨ Features

### 🎨 Design & Animation
- **Neon-Cyber Theme** - Futuristic design with glowing neon accents
- **3D Hero Section** - Three.js animated background (Particles, Torus Knot, Grid)
- **Interactive Particles** - Particle.js canvas with mouse interaction
- **Custom Cursor** - Animated custom cursor with glow effects
- **Typing Effect** - Multi-phrase typewriter animation
- **Matrix Rain Effect** - Background matrix-style animation
- **Parallax Layers** - Mouse-responsive elements
- **Hologram Cards** - Animated project cards
- **Glass-morphism** - Modern glass blur effects
- **Dark/Light Mode** - Theme toggle with localStorage persistence
- **Glitch Effect** - Text glitch animations

### 📱 Main Sections
1. **Hero Section** - 3D animated intro with live stats
2. **Professional Profile** - Complete bio and contact information
3. **Tech Stack** - Animated skill bars and technology cloud
4. **Android Roadmap** - Career progression timeline
5. **Featured Projects** - Portfolio showcase with filtering
6. **App Collection** - 27+ apps across categories
7. **Certificates** - 82+ Programming Hub certificates
8. **GitHub Ecosystem** - 33+ GitHub account cards
9. **Social Media** - 23+ social platform links
10. **Email Collection** - 21+ emails with copy functionality
11. **AI Assistant** - Interactive chatbot
12. **Blog Section** - Tech articles preview
13. **Contact Form** - Working form with validation

### 🤖 AI Powered

## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Basic web server (optional)

### Local Development

```bash
# Clone repository
git clone https://github.com/Dev-moe-kyawaung/portfolio.git
cd portfolio

# Using VS Code Live Server
code .
# Right-click index.html → Open with Live Server
#

# Or using Python
python -m http.server 8000

# Or using Node.js
npx serve .
```

### Open in browser
```
http://localhost:8000
```


### Add New Sections
1. Copy existing section `HTML` structure
2. Add new section between `<section>` tags
3. Add corresponding styles in CSS
